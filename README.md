# jev-trader

Paper-trading dashboard for Hyperliquid perpetuals, driven by Jev or Laya
forecasts. The bot runs entirely in your browser: live market data comes
straight from Hyperliquid, API keys stay in your browser, and "Laya on this
device" runs the open-weight Laya model locally (one-time ~850 MB download).
Paper trading only: nothing here can place real orders.

This repository holds only the built static site. The source, tests and
docs live in the private `onyx` repo under `experiments/jev-trader/`.
